# 📖 Tutorial Completo do Sistema Txopela Tour

## 🎯 O que é Txopela Tour?

Txopela Tour é uma plataforma de turismo que conecta turistas com locais incríveis em Inhambane, Moçambique. Permite:

- 🗺️ Descobrir locais no mapa
- 🎫 Fazer reservas
- 💬 Conversar com outros turistas
- 🤖 Obter recomendações com IA
- ⭐ Avaliar e compartilhar experiências

## 🚀 Começando

### Passo 1: Criar Conta

1. Abra `http://localhost:3000`
2. Clique em **"Criar Conta"**
3. Preencha:
   - Email: seu_email@example.com
   - Senha: Uma senha forte
   - Confirmar: Repita a senha
4. Clique **"Registrar"**
